Codenotch for Windows

A notch on the edge of your screen showing how much of your Claude, Codex, Cursor and Antigravity usage is left, and whether Claude is still working. Hover it to see details.

Download v0.3.0 (.zip)

Unzip anywhere and run codenotch.exe. Requires Windows 10/11 with the WebView2 runtime. Each user signs in to their own tools; the app only reads local sessions.
Windows port of vinzdg/codenotch (MIT).
